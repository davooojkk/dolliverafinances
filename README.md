# dolliverafinances

dolliverafinances es una web para administración financiera domestica.
Creada con el objetivo de desarrollar aprendizaje y aumentar mi nivel
como programador.

## MVP

-Agregar gastos: registrar nombre, importe y categoría.
-Visualizar gastos: mostrar todos los gastos registrados.
-Editar y eliminar gastos: modificar o borrar registros existentes.
-Filtrar gastos: visualizar gastos según su categoría.
-Calcular totales: mostrar el total gastado y los subtotales por categoría.
-Guardar datos: conservar los gastos al recargar la página mediante localStorage.

## Objetivo

Aplicar import/export, localStorage, JSON y operaciones inmutables con arrays y objetos.
Como ampliación posterior al MVP, incorporar fetch() y async/await para cargar datos iniciales.
